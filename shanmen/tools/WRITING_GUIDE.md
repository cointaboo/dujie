# 写作规范（给所有写手）

## 文体
第二人称「你」。句子短。不加形容词堆砌，靠具体动作和物件说话。
每段不超过三句。对白用「」不用引号。不出现英文单词、不用括号解释。

## 硬指标
- 每个剧情节点 700~1200 字（`txt` 正文 + `opts` 选项的 `say` 回应）
- 每个选项 2~4 个，每处 say 至少 350 字
- 每节点必须有一个「具体物件」（一双鞋、半袋米、一台药碾子、一把没有开刃的剑）
- 每个选项都要有代价，不能有明显更优解

## 数据结构
```js
const PLOTB_x = [
 {id:'唯一id', y:年份, m:月份, t:'标题', req:{flag:'某flag'},  // req 可省
  txt:`正文，用 \n\n 分段`,
  opts:[
   {n:'选项文字', fx:{mind:[2,4], peer:[5,9]}, flag:'设定flag',
    say:`选完之后的回应，350~900 字，一定要有对白`},
  ]}
];
```
属性可用：dao hp mind fame stone master peer love foe

## 禁止
- 不许写"从此以后他过上了幸福的生活"这类总结句
- 不许出现现代词汇（手机、工资、公司、项目、系统）
- 不许引用任何歌词、诗句原文、影视台词
